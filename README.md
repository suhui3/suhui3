## About Me
I love building things and making sure they actually work, whether that's a logistics platform, a web app, or a small game. Along the way I've been an exchange student in Indonesia and South Korea, helped organise campus events like UM Hackathon 2025, Dean's Cup 2024, and picked up a bit of Korean.

## What I Expect from This Course
Most of my projects so far have been "build it, ship it, move on." But real software lives for years, and I'm curious how people keep it healthy. I hope to learn:
- How to read and understand code I didn't write
- How to refactor safely and deal with technical debt
- How to use tools like SonarQube and automated tests to guide maintenance decisions
- How software evolves over time through migrations, versioning and backward compatibility
- How to work with others on real codebases through code review and collaboration

## Goals
By the end of this course, I want to write code that is easier for others to maintain, and to approach unfamiliar systems with confidence.
